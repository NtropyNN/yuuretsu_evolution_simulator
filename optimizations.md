# Оптимизации для симулятора эволюции

## 1. Оптимизации производительности JavaScript

- [ ] **Оптимизация функции `loopFunc`**: Вместо перебора всех ботов и мертвых ботов в каждом цикле, можно использовать более эффективные структуры данных, такие как массивы вместо объектов для хранения ботов.
- [ ] **Оптимизация функции `live` в классе `Bot`**: Уменьшить количество вызовов `moveDnaPos` и оптимизировать логику выбора действий бота.
- [ ] **Оптимизация функции `mutatedDna`**: Уменьшить количество вызовов `PIX.random.num` внутри цикла.
- [ ] **Использование object pooling для ботов**: Вместо создания и удаления объектов ботов, использовать пул объектов для повторного использования.
- [ ] **Оптимизация функции `assign`**: Использовать более эффективный способ генерации уникальных ID, например, инкрементный счетчик вместо случайных чисел.

## 2. Улучшения отрисовки Canvas

- [ ] **Использование offscreen canvas**: Для отрисовки фона и графиков использовать offscreen canvas, чтобы уменьшить нагрузку на основной поток.
- [ ] **Оптимизация отрисовки ботов**: Вместо отрисовки каждого бота по отдельности, использовать batch рендеринг для отрисовки всех ботов за один вызов.
- [ ] **Оптимизация отрисовки DNA**: Кэшировать отрисовку DNA в отдельном canvas и обновлять только при изменении.
- [ ] **Оптимизация отрисовки графиков**: Использовать более эффективные алгоритмы для отрисовки графиков, например, использовать Path2D для отрисовки линий.

## 3. Оптимизации работы с памятью

- [ ] **Уменьшение количества создаваемых объектов**: Минимизировать количество создаваемых объектов в цикле, особенно в функциях `live` и `mutatedDna`.
- [ ] **Использование typed arrays**: Для хранения DNA и других числовых данных использовать typed arrays вместо обычных массивов.
- [ ] **Оптимизация хранения цветов**: Использовать более компактные представления цветов, например, хранить цвета как одно 32-битное число вместо массива из трех чисел.
- [ ] **Очистка неиспользуемых ресурсов**: Правильно очищать canvas и другие ресурсы, которые больше не используются.

## 4. Возможные узкие места в коде

- [ ] **Функция `getRandomEmpty` в классе `Grid`**: Эта функция может быть медленной при высокой заполненности сетки. Можно оптимизировать, храня список пустых ячеек.
- [ ] **Функция `normalCoords`**: Эта функция вызывается часто и может быть оптимизирована, возможно, с помощью кэширования.
- [x] **Функция `calcLight`**: Эта функция вызывается для каждого бота в каждом цикле. Можно кэшировать значения освещенности для каждой строки.
- [ ] **Функция `showDna`**: Эта функция вызывается при отрисовке каждого выбранного бота и может быть оптимизирована с помощью кэширования отрисовки.
